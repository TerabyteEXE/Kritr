GETTING STARTED

Install Kritr, open the player, then use ADD SONGS or ADD MUSIC FOLDER. Folder imports are remembered by the desktop app, so your library returns the next time Kritr starts.

MUSIC LIBRARY

Use search, favorites and sorting to manage larger libraries. Rescan finds new music in previously added folders. Removing a track from Kritr does not delete the original audio file.

PLAYER

Kritr supports play/pause, seek, volume, playback speed, shuffle, repeat, queueing and persistent playback state. Mini mode turns the player into a compact desktop companion.

PETS

Choose a pet in the PET tab, give it a name and select its activity level. Pets use subtle text animations and react occasionally to playback without constantly changing identity.

THEMES

The built-in themes are grouped by color family. For a completely personal look, choose CUSTOM and use the Advanced color controls. Your custom palette is saved automatically.

ADVANCED SETTINGS

The Advanced panel controls album size, visualizer height, pet size, control size, spacing and border weight. Its live player preview mirrors the actual main widget so you can tune the layout before returning to the Player tab.

TROUBLESHOOTING

Missing music

If files were moved or renamed outside Kritr, rescan the library or re-add the folder.

Window is off screen

Switch window mode or reset Kritr settings. The desktop build also validates saved window placement on launch.

Artwork looks wrong

Kritr uses embedded album artwork when available. A track without embedded art falls back to the themed Kritr cover.

Need a clean start?

Use RESET in Settings. Your actual music files are never deleted.
